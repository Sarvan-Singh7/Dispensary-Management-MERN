College Dispensary Management System
A full-stack MERN application to manage college dispensary operations with role-based portals for Admin, Staff, and Students.

🚧 Status: In Progress — Frontend UI complete, backend integration ongoing.

Tech Stack

Frontend: React.js, CSS, Vite
Backend: Node.js, Express.js
Database: MongoDB (Mongoose)
Auth: JWT, Bcrypt, NodeMailer (OTP)
Storage: Cloudinary

Features

Role-based access — Admin, Staff, and Student portals
Medicine inventory with real-time stock tracking
Student registration and health record management
OTP-based password reset via email
Admin-only staff management
